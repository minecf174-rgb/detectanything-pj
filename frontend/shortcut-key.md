# Keyboard shortcuts (Frontend)

คีย์ลัดด้านล่างใช้ในหน้า **Annotate** เมื่อไม่ได้กำลังพิมพ์ในช่องข้อความหรือเปิดหน้าต่าง modal อยู่ ยกเว้นคีย์ลัด **Review no-box** ที่ใช้ภายใน modal นั้นโดยเฉพาะ การกดปุ่มขณะระบบกำลังบันทึก/โหลดข้อมูลจะไม่เริ่มคำสั่งใหม่

นี่คือ **ค่าเริ่มต้น** ผู้ใช้เปลี่ยนได้ที่ปุ่ม **Shortcuts** บนแถบด้านบนของ Dashboard หรือหน้าโปรเจกต์ คลิกคีย์ของ action ที่ต้องการแล้วกดคีย์ใหม่ ระบบเตือนคีย์ชนกันใน workflow เดียวกัน มีปุ่ม Clear, Reset ราย action และ Reset all ค่าที่ตั้งจะเก็บไว้ในเบราว์เซอร์นี้แยกตามบัญชี ปุ่มบนหน้าทำงานยังคลิกได้ตามเดิม และจะแสดงคีย์ที่ตั้งปัจจุบัน

## ใช้ได้ทั้ง Object Detection และ Pose Estimation

| ปุ่ม | การทำงาน |
| --- | --- |
| `←` / `→` | รูปก่อนหน้า / รูปถัดไป (ใช้ไม่ได้ระหว่างแก้ label หรือมีจุด Pose ที่คลิกค้างอยู่) |
| `Ctrl+S` / `Cmd+S` (`Mod+S` ในหน้าตั้งค่า) | บันทึก manual draft ที่ทำครบแล้ว หรือ Save revision/Save corrected เมื่อเปิดแผงแก้ไข |
| `Ctrl+Z` / `Cmd+Z` (`Mod+Z` ในหน้าตั้งค่า) | Undo จุด Pose ล่าสุด, กล่อง draft ล่าสุด หรือการแก้ไขล่าสุดในแผง Edit/Review |
| `Esc` | Cancel แผงแก้ไขหรือ Pose ที่กำลังวาง; ถ้ามีการแก้ค้างอยู่จะถามก่อนทิ้ง |
| `D` | เปิด **Edit labels** เพื่อแก้ label ที่บันทึกและอนุมัติแล้วของรูปปัจจุบัน (ต้องไม่มี draft ค้างอยู่) |
| `V` | ยืนยันรูปที่กำลังดูเป็น Verified negative ในหน้า Annotate: กรอบที่แสดงจะหายไปและผล Pending ของรูปถูกปฏิเสธ ไม่ต้องลบกรอบหรือกด Accept all ก่อน แต่ต้องไม่มี draft ค้างอยู่ |

## Object Detection

| ปุ่ม | การทำงาน |
| --- | --- |
| `1`–`9` | เลือกคลาสตามลำดับที่แสดงในแถบ Classes |
| `Backspace` / `Delete` | ลบกล่อง draft ล่าสุด; ในแผง Edit/Review จะลบกล่องที่เลือก |

## Pose Estimation: สร้าง Pose ใหม่

| ปุ่ม | การทำงาน |
| --- | --- |
| `A` | เริ่มเพิ่ม Pose ของคนใหม่ แล้วคลิกจุดตามลำดับ 17 จุด |
| `1` | ตั้งจุดถัดไปเป็น Visible ก่อนคลิกบนภาพ |
| `2` | ตั้งจุดถัดไปเป็น Occluded ก่อนคลิกบนภาพ |
| `3` | บันทึกจุดถัดไปเป็น Outside frame และข้ามไปจุดต่อไปทันที |
| `Ctrl+Z` / `Cmd+Z` | ย้อนจุดล่าสุดที่คลิกหรือข้าม (`Backspace` / `Delete` ยังใช้ได้) |
| `Esc` | ยกเลิก Pose ที่กำลังวาง; ถ้าวางจุดไปแล้วระบบจะถามก่อนทิ้ง |

หลังทำครบ 17 จุด ระบบจะเพิ่ม Pose เป็น draft จากนั้นกด `Ctrl+S` / `Cmd+S` เพื่อบันทึก ถ้าทำจุดค้างอยู่ต้องทำให้ครบหรือกด **Cancel** ก่อนเปลี่ยนรูป

## Pose Estimation: แก้จุดที่มีอยู่

กด `D` หรือ **Edit labels** สำหรับ label ที่อนุมัติแล้ว หรือกด `E` / **Edit** ใน Review Queue สำหรับผล Auto-label ที่ยัง Pending แล้วเลือก Person:

| ปุ่ม | การทำงาน |
| --- | --- |
| `Q` | เลือก keypoint ก่อนหน้า |
| `E` | เลือก keypoint ถัดไป |
| `1` | เลือกโหมด Visible สำหรับจุดที่เลือก แล้วคลิกภาพเพื่อวาง/ย้ายจุด |
| `2` | เลือกโหมด Occluded สำหรับจุดที่เลือก แล้วคลิกภาพเพื่อวาง/ย้ายจุด |
| `3` | ตั้งจุดที่เลือกเป็น Outside frame และข้ามไปจุดถัดไปทันที |
| `Ctrl+Z` / `Cmd+Z` | ย้อนการแก้ไขล่าสุดในแผง Edit/Review |
| `Esc` | ยกเลิกการแก้ไข; ถ้ามีการเปลี่ยนแปลงจะถามก่อนทิ้ง |

`Q/E` หยุดที่จุด 1 และ 17 ไม่วนกลับ เมื่อคลิกบนภาพเพื่อย้ายจุดที่เลือก ระบบจะเลือกจุดถัดไปให้อัตโนมัติ คีย์ `1/2` ยังไม่เปลี่ยน label เดิมจนกว่าจะคลิกภาพ ส่วน `3` เปลี่ยนทันที กด `Ctrl+S` / `Cmd+S` เพื่อ Save revision/Save corrected หรือคลิกปุ่มเดิมได้ คีย์ลัดสองช่วงตั้งแยกกันได้ที่ **Shortcuts → Pose · Add / Pose · Edit**

## ตรวจผล Auto-label ที่ Pending

ใช้เมื่อรูปปัจจุบันมีผล Pending **เพียงชุดเดียว** และไม่มี draft หรือ Pose ที่ทำค้างอยู่:

| ปุ่ม | การทำงาน |
| --- | --- |
| `Y` | Accept ผล Pending ของรูปปัจจุบัน |
| `N` | Reject ผล Pending ของรูปปัจจุบัน |
| `E` | เปิด Edit ของผล Pending เพื่อแก้ก่อนบันทึก |

หลัง Accept/Reject ระบบ **ยังอยู่รูปเดิม**; ใช้ `→` เพื่อไปดูรูปถัดไป หากรูปเดียวมี Pending หลายชุด ให้เลือกชุดที่จะจัดการจาก **Review Queue** ด้วยเมาส์เพื่อไม่ให้คีย์ลัดสั่งผิดชุด

`E` ใช้กับผล Auto-label ที่ยัง Pending เท่านั้น ส่วน `D` ใช้กับ label ที่บันทึกและอนุมัติแล้ว จึงไม่เปิดผิดโหมดแม้รูปเดียวกันจะมีทั้งสองอย่าง

**Accept รูปที่โมเดลไม่พบกรอบไม่ได้หมายถึง Verified negative** ตรวจรูปแล้วกด `V` ในหน้า Annotate ได้ทันที หรือใช้ **Select image → Review no-box** เพื่อไล่ตรวจเป็นคิว

## ตรวจรูปที่โมเดลไม่พบกรอบ (Review no-box)

ในหน้าต่าง **Select image** กด `Esc` เพื่อปิดหน้าต่างได้ แม้กำลังพิมพ์ในช่องค้นหา; ถ้าอยู่ใน **Review no-box** การกด `Esc` ครั้งแรกจะกลับไป Select image และกดอีกครั้งจึงปิดหน้าต่าง

เมื่อมีผล Auto-label ที่ **Accepted** และไม่พบกรอบ ปุ่ม **Review no-box** จะปรากฏใน **Select image** จากนั้นตรวจรูปทีละรูปในหน้านี้:

| ปุ่ม | การทำงาน |
| --- | --- |
| `V` | ยืนยันว่ารูปปัจจุบันไม่มีวัตถุเป้าหมาย (Verified negative) เหมือนกด **Confirm no objects** |
| `←` / `→` | เลื่อนไปรูปก่อนหน้า / ถัดไป โดยใช้คีย์ Navigation ที่ตั้งไว้ |
| `Esc` | กลับไปหน้า Select image |

ตั้งคีย์ `V` ใหม่ได้ที่ **Shortcuts → No-box review → Verify negative** บน Dashboard หรือหน้าโปรเจกต์ ถ้ารูปมีวัตถุ ห้ามกด Verify; ให้เลือก **Object visible · draw label** แทน

คีย์ `V` ในหน้า Annotate ตั้งแยกได้ที่ **Shortcuts → Negative verification** โดยไม่กระทบคีย์ของ Review no-box
