# Keyboard shortcuts (Frontend)

คีย์ลัดด้านล่างใช้ในหน้า **Annotate** เมื่อไม่ได้กำลังพิมพ์ในช่องข้อความหรือเปิดหน้าต่าง modal อยู่ การกดปุ่มขณะระบบกำลังบันทึก/โหลดข้อมูลจะไม่เริ่มคำสั่งใหม่

นี่คือ **ค่าเริ่มต้น** ผู้ใช้เปลี่ยนได้ที่ปุ่ม **Shortcuts** บนแถบด้านบนของ Dashboard หรือหน้าโปรเจกต์ คลิกคีย์ของ action ที่ต้องการแล้วกดคีย์ใหม่ ระบบเตือนคีย์ชนกันใน workflow เดียวกัน มีปุ่ม Clear, Reset ราย action และ Reset all ค่าที่ตั้งจะเก็บไว้ในเบราว์เซอร์นี้แยกตามบัญชี ปุ่มบนหน้าทำงานยังคลิกได้ตามเดิม และจะแสดงคีย์ที่ตั้งปัจจุบัน

## ใช้ได้ทั้ง Object Detection และ Pose Estimation

| ปุ่ม | การทำงาน |
| --- | --- |
| `←` / `→` | รูปก่อนหน้า / รูปถัดไป (ใช้ไม่ได้ระหว่างแก้ label หรือมีจุด Pose ที่คลิกค้างอยู่) |
| `Ctrl+S` / `Cmd+S` (`Mod+S` ในหน้าตั้งค่า) | บันทึก manual draft ที่ทำครบแล้ว หรือ Save revision/Save corrected เมื่อเปิดแผงแก้ไข |
| `Esc` | Cancel แผงแก้ไขหรือ Pose ที่กำลังวาง; ถ้ามีการแก้ค้างอยู่จะถามก่อนทิ้ง |

## Object Detection

| ปุ่ม | การทำงาน |
| --- | --- |
| `1`–`9` | เลือกคลาสตามลำดับที่แสดงในแถบ Classes |
| `Backspace` / `Delete` | ลบกล่อง draft ล่าสุด; ในแผง Edit/Review จะลบกล่องที่เลือก |

## Pose Estimation: สร้าง Pose ใหม่

| ปุ่ม | การทำงาน |
| --- | --- |
| `A` | เริ่มเพิ่ม Pose ของคนใหม่ แล้วคลิกจุดตามลำดับ 17 จุด |
| `1` | ตั้งจุดถัดไปเป็น Visible ก่อนคลิกบนภาพ |
| `2` | ตั้งจุดถัดไปเป็น Occluded ก่อนคลิกบนภาพ |
| `3` | บันทึกจุดถัดไปเป็น Outside frame และข้ามไปจุดต่อไปทันที |
| `Backspace` / `Delete` | ย้อนจุดล่าสุดที่คลิกหรือข้าม |

หลังทำครบ 17 จุด ระบบจะเพิ่ม Pose เป็น draft จากนั้นกด `Ctrl+S` / `Cmd+S` เพื่อบันทึก ถ้าทำจุดค้างอยู่ต้องทำให้ครบหรือกด **Cancel** ก่อนเปลี่ยนรูป

## Pose Estimation: แก้จุดที่มีอยู่

กด **Edit labels** สำหรับ label ที่อนุมัติแล้ว หรือกด **Edit** ใน Review Queue สำหรับผล Auto-label ที่ยัง Pending แล้วเลือก Person:

| ปุ่ม | การทำงาน |
| --- | --- |
| `Q` | เลือก keypoint ก่อนหน้า |
| `E` | เลือก keypoint ถัดไป |

`Q/E` หยุดที่จุด 1 และ 17 ไม่วนกลับ เมื่อคลิกบนภาพเพื่อย้ายจุดที่เลือก ระบบจะเลือกจุดถัดไปให้อัตโนมัติ กด `Ctrl+S` / `Cmd+S` เพื่อ Save revision/Save corrected หรือคลิกปุ่มเดิมได้

## ตรวจผล Auto-label ที่ Pending

ใช้เมื่อรูปปัจจุบันมีผล Pending **เพียงชุดเดียว** และไม่มี draft หรือ Pose ที่ทำค้างอยู่:

| ปุ่ม | การทำงาน |
| --- | --- |
| `Y` | Accept ผล Pending ของรูปปัจจุบัน |
| `N` | Reject ผล Pending ของรูปปัจจุบัน |
| `E` | เปิด Edit ของผล Pending เพื่อแก้ก่อนบันทึก |

หลัง Accept/Reject ระบบ **ยังอยู่รูปเดิม**; ใช้ `→` เพื่อไปดูรูปถัดไป หากรูปเดียวมี Pending หลายชุด ให้เลือกชุดที่จะจัดการจาก **Review Queue** ด้วยเมาส์เพื่อไม่ให้คีย์ลัดสั่งผิดชุด

**Accept รูปที่โมเดลไม่พบกรอบไม่ได้หมายถึง Verified negative** ต้องตรวจและกดยืนยัน Negative แยกใน **Select image → Review no-box**
