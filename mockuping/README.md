# CV Platform Early UI Mockup

This folder is a standalone static mockup based on the oldest available frontend backup.

- No API calls
- No authentication
- No database connection
- No dependency on the current frontend
- All visible content is sample data

Open `index.html` directly in a browser. A static server is optional:

```bash
cd "/Users/apple02/detect anything/mockuping"
python3 -m http.server 4170
```

Then open `http://127.0.0.1:4170`.
